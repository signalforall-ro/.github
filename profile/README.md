# Signal For All

**Comunicații accesibile, oriunde — chiar și acolo unde semnalul nu mai există.**

Aplicație Android pentru comunicare prin voce, hands-free, prin radiouri mesh LoRa. Construită din primul rând al specificațiilor pentru utilizatori cu deficiențe vizuale. Funcționează unde nu există semnal, fără internet, fără atingerea ecranului.

[**signalforall.ro →**](https://signalforall.ro)

---

## Despre proiect

Signal For All este un proiect civic-tech open-source dezvoltat în România. Folosim protocolul Meshtastic peste LoRa (banda 868 MHz, conform Decizia ANCOM nr. 150/2012, fără obligativitatea licenței individuale) pentru a permite comunicații prin voce între oameni aflați în zone fără infrastructură celulară.

**Diferența principală**: arhitectura este *accessibility-native*, nu adaptată ulterior. Construim de la zero pentru folosire hands-free — pentru oameni care merg cu bastonul în medii zgomotoase, voluntari de teren în natură cu mâinile ocupate, comunități cu acoperire mobilă inconsistentă.

> **Ce este și ce nu este Signal For All**
>
> Este un sistem **complementar** de comunicare. Nu este un sistem de urgență, nu înlocuiește 112, TETRA sau radiourile profesionale. Această claritate este esențială pentru poziționarea proiectului.

## Valori

- **Open-source din primul commit.** Codul, documentația, deciziile sunt publice.
- **Accessibility-native, nu adaptat ulterior.** Utilizatorii cu deficiențe vizuale sunt utilizatori principali, nu un caz secundar.
- **Onestitate asupra limitărilor.** Spunem clar ce nu este sistemul.
- **Disciplină peste ambiție.** Faze clare cu criterii reale de avansare. NO-GO nu este eșec — este disciplină.
